# DETARA

DETARA adalah prototipe Progressive Web App (PWA) Sistem Peringatan Dini Kebakaran Hutan dan Lahan Berbasis IoT, Edge AI, dan SIG dengan Verifikasi Berlapis serta Respons Komunitas di Provinsi Jambi.

Dikembangkan untuk ajang **Yogyakarta Emerging Scientist Competition (YESC) 2026** pada subtema *Environmental Sustainability*.
